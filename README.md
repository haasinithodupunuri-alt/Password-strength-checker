# Password Strength Checker

A simple C program that checks the strength of a password.

## Features

- Checks for uppercase letters
- Checks for lowercase letters
- Checks for digits
- Checks for special characters
- Displays whether the password is strong or weak

## Technologies Used

- C
- GCC Compiler

## How to Run

Compile the program:

gcc password_checker.c -o password_checker

Run it:

./password_checker
